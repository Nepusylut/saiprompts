# Advanced Prompt Engineering & Media Embeds

Welcome to the sample MDX article for **PromptCraft Blog**. This document demonstrates how MDX components render seamlessly alongside markdown headers, code blocks, parameter sets, and responsive video embeds.

---

## 1. Interactive One-Click Copy Prompt Component (`<PromptCard />`)

Below is an interactive `<PromptCard />` component displaying a target AI tool badge (`Claude`), parameter badges (`Model`, `Thinking Token Budget`), and a **Copy Prompt** button with native clipboard feedback.

<PromptCard
  prompt={{
    id: "prompt-sample-mdx-claude",
    title: "Principal Software Architect & Code Reviewer",
    description: "Enforces SOLID principles, type safety, modular design, and security checks.",
    tool: "Claude",
    category: "Tech Prompts",
    copyCount: 4218,
    rating: 4.9,
    parameters: [
      { label: "Model", value: "Claude 3.7 Sonnet", badgeType: "model" },
      { label: "Thinking", value: "Budget 4000 tokens", badgeType: "setting" },
      { label: "Style", value: "Strict & Modular", badgeType: "param" }
    ],
    tags: ["Claude 3.7", "Architecture", "TypeScript"],
    promptText: `[SYSTEM PROMPT: PRINCIPAL SOFTWARE ARCHITECT]

Role: You are a Staff Level Software Architect specializing in TypeScript & React 19.

Your directive:
1. Analyze code strictly for maintainability, security vulnerabilities, edge-case race conditions, and performance bottlenecks.
2. Enforce module separation: files must not exceed 250 lines; export typed modular contracts.
3. Every suggestion must include a concise rationale and a direct concrete refactored code block.`
  }}
/>
